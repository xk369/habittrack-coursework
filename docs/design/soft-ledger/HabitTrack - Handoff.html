HabitTrack
Soft Ledger.

Спокойный, измеримый «учётный журнал» привычек. Тёплая кремовая основа, графитовые тексты, мшисто-зелёный sage как единственный акцент, heatmap-сетка дней как главный визуальный мотив. Этот документ фиксирует токены, типографику, компоненты и спецификации трёх ключевых экранов — достаточно, чтобы реализовать дизайн на React + TypeScript + Tailwind без визуальных компромиссов.

Stack React · TypeScript · Vite · Tailwind
Density Desktop · 1280 baseline
Темы Light · cream-based
Локаль RU · LTR

Spacing

Шкала на базе 4px. Используйте Tailwind-spacing as-is — она 1-в-1 соответствует токенам системы. Edge-paddings экранов — 28px (Tailwind px-7), внутренние паддинги карточек — 16–24px. 

// рекомендованные значения
edge:    28px   // boundary экрана
card:    18–24px // внутренний padding карточек
section: 16px   // gap между блоками одной секции
item:    10–14px // gap между равноправными элементами
inline:  6–8px   // gap между иконкой и текстом

Radii

Pill-радиус для бейджей — 999px.

Shadows

Драп-теней почти нет. Soft Ledger использует bordered + inset-структуру вместо elevation — это часть характера. Допустимы только:

  • inset 0 1px 0 rgba(255,255,255,0.15) — на sage-кнопках и filled-чекбоксах для лёгкого блика;
  • тонкая box-shadow: 0 0 0 3px var(--sage-50) — фокус-кольцо у активной mode-card.

avoid Drop-shadow в духе 0 4px 12px rgba(0,0,0,.1) и подобные «pretty SaaS»-тени. Они ломают язык системы.

Motion

transitions: 'background 120ms, border-color 120ms, color 120ms, transform 120ms'
easing:      'cubic-bezier(.2, .7, .3, 1)' // «settle» — для всех hover/state
page:        160–220ms // смена экранов, появление toast

Анимаций немного и они короткие. Никаких bounce/spring-кривых, никаких motion-design-флойридов — приложение про спокойную дисциплину.

§02TYPOGRAPHY

Типографика

Два шрифта. Geist для всего интерфейса. Geist Mono — для чисел, метрик, ID, дат, технических подписей. Это правило не для красоты — оно делает количественные данные читаемыми как в финансовом отчёте.

Шрифтовые стеки

--font-sans: 'Geist', ui-sans-serif, system-ui, sans-serif;
--font-mono: 'Geist Mono', ui-monospace, 'JetBrains Mono', monospace;

Подключение через Google Fonts: family=Geist:wght@300;400;500;600;700&family=Geist+Mono:wght@400;500;600. Включайте font-feature-settings: 'tnum', 'zero' для всех моноширинных чисел (utility-класс .ht-num в репозитории).

Правила применения

  • Geist Mono — всегда для: процентов, дней, дат (07:14, 17 мая), ID (HABIT_8F3A), счётчиков (12/116).
  • Geist — для всего остального: заголовки, описания, кнопки, навигация.
  • Eyebrow — это технический ярлык над секцией («СЕГОДНЯ · ПРОГРЕСС»); не заголовок.
  • Не используйте bold-веса 600/700 для UI — это перебор для спокойной системы. 500 — потолок.
  • Tabular numbers (font-variant-numeric: tabular-nums) обязательно везде, где цифры стоят в столбец или сравниваются.

§04SCREENS

Спецификация трёх ключевых экранов

Layout, состав блоков, визуальные приоритеты и правила responsive. Для каждого экрана зафиксированы элементы, которые критично сохранить при переносе в код.

Dashboard · главный экран

Baseline ширина 1280px. Edge-padding 28px. Гид по вертикальной иерархии:

01 · top navStandard 56px header. Активный таб — «Сегодня».
02 · hero card Карточка-обёртка radius 20px. Разделена на 2 колонки + KPI-strip снизу.
Left (60%): eyebrow с датой → greeting H1 → подсказка → две кнопки (accent «Отметить ближайшую» + secondary «Новая привычка»).
Right (40%): sage-градиентный блок «СЕГОДНЯ · ПРОГРЕСС» — hero-число «3 / 6» (76 / mono), процент, прогресс-бар 10px, точечный рейл из 6 чекбоксов по привычкам.
KPI-strip снизу: 4 ячейки по 1fr, разделены 1px. Лучший streak (highlight sage) · Compliance 30 дней · Активных · Отметок всего. Каждое число 40 / mono.
03 · year heatmap panel Своя карточка radius 14px. Заголовок «Карта регулярности» + H2 «365 дней дисциплины» с моно-числом 365.
Справа в шапке: 3 моно-stat («Идеальных дней / Идеальных недель / Пропусков») + легенда «Меньше□□□□□Больше».
Сам heatmap — 52 недели × 7 дней, cell 13px, gap 4px, monthLabels. Фон inset.
04 · habit cards grid Eyebrow «СЕГОДНЯ · ВТОРНИК» → H2 «Привычки на сегодня» + микро-сводка («6 запланировано · 3 выполнено · 3 в ожидании»).
Справа — segment-таб Активные/Все/Архив.
Сетка 2 колонки, gap 14px. Карточка см. §c-cards «HABIT CARD».
05 · create dashed tile Полноширотная dashed-карточка radius 14px. Иконка-квадрат + двухстрочный текст + arrow-right. Действует как нижний CTA-якорь сетки.

Визуальные приоритеты

  1. Hero-число «3 / 6» — самый крупный элемент экрана.
  2. Greeting H1 — главный текстовый якорь.
  3. KPI-strip — секцндарная аналитика.
  4. Year heatmap — равноценный визуальный блок-хук.
  5. Habit cards — рабочая зона, более ровная плотность.

Responsive

  • ≥1200 — макет 1-в-1 как в макете.
  • 1024–1199 — KPI-strip сворачивается в 2×2, hero становится одноколоночным.
  • 768–1023 — habit cards 1 колонка, year heatmap прокручивается горизонтально (сохранить cellSize).
  • <768 — не в скоупе первой итерации, но если придётся: stack everything, weekday-strip скрывается в карточке.

Критично сохранить

  • Sage hero-блок справа — он визуально и эмоционально несёт экран.
  • Year heatmap должен быть в отдельной framed-карточке, не прижатой к hero.
  • Карточка привычки: streak справа сверху как доминантная цифра, heatmap внутри inset-полосы.
  • Только один accent-CTA на экране (в hero либо в карточке, не оба).

Habit Detail · центр управления привычкой

02 · hero strip Карточка radius 20px. Двухколоночный grid 1fr auto.
Left: status badge active + mono-meta (ID, дата создания, дней в работе) → Display L H1 (42px) → описание → schedule-meta inline (weekday-strip 28px + расписание + время напоминания + следующая дата).
Right: action-stack 240px ширины — accent-кнопка lg «Отметить сегодня» fullWidth + строка из 3 кнопок (Изменить · В архив · 30×30 destructive-иконка).
KPI-strip снизу: 4 big-metric (48 / mono). Первая (streak) — sage-градиентный фон-highlight.
03 · viz panel (1.55fr) Heatmap-карточка radius 14: header с tab-segment (Год / 6 мес / 3 мес / Месяц), inset-зона с heatmap 26 недель × 18px cellSize, footer с тремя моно-stat и легендой.
Под ней — две карточки в grid 1.4fr 1fr: Compliance 30 дней с big-number 32 / sparkline 420×62; и Weekly bars — 7 столбиков с track-fill (sage-600 если full, sage-400 если partial).
04 · history aside (1fr) Не одна большая панель, а стек из трёх блоков через gap 14px:

2. This week strip — 7 day-cards в равной grid. Каждая: eyebrow день + число + sage-fill 18×18 индикатор. Today-карточка — sage-tinted, future-карточка — inset с line-border.
3. Full history — список со sticky-month-headers (eyebrow месяц + progress-bar 64×4 + «x/y» mono). Каждый history row см. §c-history.

Визуальные приоритеты

  1. H1 «Утренняя медитация» — основной якорь.
  2. Big-metric streak (48 / sage-highlight) — самая весомая цифра.
  3. Sage hero «47-й день подряд» в правой колонке — эмоциональный якорь.
  4. Year heatmap — рациональный якорь.
  5. Список истории — сканируемая рабочая зона.

Responsive

  • ≥1200 — двухколоночный layout сохраняется.
  • 1024–1199 — history-aside уходит под viz-панель в одну колонку, без потери порядка.
  • <1024 — KPI-strip 2×2, action-stack hero растягивается на всю ширину под title.

Критично сохранить

  • Three-block структура aside (Today / This week / Full history) — она и даёт «ритм» экрана.
  • Sage-highlight на первой KPI-ячейке (streak) — единственное место на экране с sage-fill.
  • Размер big-metric 48px не должен опускаться ниже 40.
  • «Снять отметку» кнопка должна быть видна на Today hero, не спрятана в меню.

Create Habit · форма

Двухколоночный layout 1fr 400px. Слева — структурированная форма-документ, справа — live preview rail.

01 · headerBreadcrumb + Display M H1 «Новая привычка» + lede 14 ink-2. Справа — ghost «Отмена» и accent «Создать привычку» (в disabled state по умолчанию).
02 · form card Radius 20px. Состоит из трёх FormSection, каждая — двухколоночный grid 220px 1fr: левая колонка — sage-tag номер § + название секции + caption, правая — поля.
§01 Что вы хотите делать — Title input (46px, счётчик символов справа) + Purpose textarea + hints.
§02 Когда выполнять — пара ModeCard radio («Ежедневно» / «Выбранные дни», активный с sage-ring), затем weekday picker контейнер (см. §c-weekday — interactive 52–64px вариант), validation-message внутри, presets-чипы внизу.
§03 Напоминание — ReminderChip с моно-временем + dashed «+ Ещё одно» добавление.
03 · footer actionsInset-полоса в форме: слева info-микротекст, справа ghost-«Отмена» + accent-«Создать привычку» (disabled когда validation fails).
04 · preview rail (400px) Sticky top: 18. Стек из трёх блоков:
1. Habit card preview — упрощённая копия карточки с Dashboard, отражает текущее состояние формы (включая danger-meta при пустых днях).
2. Year projection — EmptyHeatmap (dashed) или partial-filled при выбранных днях, + три ProjStat «ДНЕЙ В НЕДЕЛЮ / В МЕСЯЦ / В ГОД».
3. Validation checklist — 4 CheckItem строки (Название / Цель / Режим / Дни) с зелёной галочкой или красным X.

Визуальные приоритеты

  1. H1 «Новая привычка» — якорь страницы.
  2. Weekday picker (когда невалиден) — красная рамка делает его центром внимания.
  3. Mode-cards — primary выбор пользователя, sage-ring на активной.
  4. Preview rail — secondary, тихий, но информативный.

Responsive

  • ≥1100 — двухколоночный layout с sticky preview.
  • 768–1099 — preview rail сворачивается в нижний sticky-bar (или в раскрывающуюся секцию), весь экран — одна колонка.

Критично сохранить

  • FormSection с sage-tag номером — это и есть «документная» подача формы.
  • Mode-cards со встроенным radio (а не radio-buttons рядом) — критично для визуальной цельности.
  • Validation-message внутри контейнера weekday-picker, не снаружи.
  • Preview rail должен оставаться реактивным к данным, не статическим.
§05BOUNDARIES

Что обязательно сохранить, что допустимо упростить

Soft Ledger держится на нескольких принципах. Если они нарушены — это уже другой стиль. Всё остальное — пространство для разумных инженерных компромиссов.

Обязательно сохранить

must ТЁПЛАЯ КРЕМОВАЯ БАЗА Никаких чисто-белых поверхностей. Все surfaces — в диапазоне oklch(0.94–0.99 / 0.008–0.018 / 75–85). Это и есть «soft» в названии.
must ЕДИНСТВЕННЫЙ АКЦЕНТ — SAGE Никакого второго акцентного цвета. Sage используется только для прогресса, успеха и единственного primary CTA на экране.
must ЧИСЛА — ВСЕГДА GEIST MONO Любая метрика, дата, ID — Geist Mono с tabular-nums. Это создаёт «ритм учётного журнала».
must HEATMAP КАК ГЛАВНЫЙ МОТИВ Heatmap присутствует на всех трёх ключевых экранах. Не круги, не кольца Apple, не bar-charts как главный визуал.
must BORDERED + INSET КАРТОЧКИ Структура «карточка как документ»: тонкая граница, внутренние делители, inset-зоны. Без drop-shadow.
must СПОКОЙНЫЙ ЯЗЫК ИНТЕРФЕЙСА Никаких восклицаний, эмодзи, gamification-копии. «Отметить сегодня», а не «🔥 Поехали!». Тон личный, но сдержанный.
must ТОЛЬКО ОДИН ACCENT-CTA НА ЭКРАН Sage-кнопка — самый сильный сигнал. Если их две, они конкурируют и обе теряют вес.
must EYEBROW MONO-ЛЕЙБЛЫ «СЕГОДНЯ · ПРОГРЕСС», «ТЕКУЩИЙ STREAK» — обязательная типографическая ткань всех секций и метрик.

Допустимо упростить при React-реализации

ok to simplify SVG ИКОНКИ Кастомные ручные SVG можно заменить на lucide-react с тем же stroke-width (1.5–1.6). Размеры и цвета сохранить.
ok to simplify HEATMAP-ГЕНЕРАЦИЯ В макете данные псевдо-случайные через seed. В проде — реальные данные completion. Можно использовать react-calendar-heatmap с кастомным classForValue, мапя в наши 5 ступеней.
ok to simplify SPARKLINE Наш в-line SVG достаточен. Если уже стоит Recharts/Victory — используйте, без gridlines и осей.
ok to simplify AVATAR Градиентный кружок с инициалами в дизайне — placeholder. Замените на <img> с fallback на инициалы.
ok to simplify ANIMATIONS Все transitions — 120ms на цвет/border. Никаких scrub-анимаций, parallax, layered motion. Если не успеваете — пропустите анимации первой версии, они не несут смысл.
ok to simplify WEEKLY BARS Если короче по времени реализации — замените на горизонтальные progress-bars с подписями недель.
ok to simplify PREVIEW RAIL Live-preview в Create Habit можно реализовать как простой useState-controlled блок без debounce. Year-projection не обязателен в MVP — оставьте только habit card preview + checklist.
ok to simplify DESIGN CANVAS DesignCanvas — это инструмент для показа дизайна. В коде не воспроизводите. Каждый экран — самостоятельный route.

Чего точно не делать

do not Drop-shadow на карточках Любая «box-shadow: 0 4px 12px rgba(0,0,0,.1)» немедленно превращает дизайн в обычный SaaS-template.
do not Второй акцентный цвет Синий для info, фиолетовый для premium, жёлтый для warning — это не наша система. Только sage + ink + warm-cream.
do not Эмодзи и gamification 🔥 для streak, ✨ для «отлично», конфетти на отметку. Это нарушает характер.
do not Inter/Roboto/system fonts Geist обязателен. Если падает CDN — fallback на system-ui, но никогда не подставляйте Inter как «альтернативу».
