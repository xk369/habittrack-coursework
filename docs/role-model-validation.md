# Валидация ролевой модели

## Назначение

Документ для проектирования и учета проверок ролевой модели, включая запрет
admin-доступа обычному пользователю и отклонение невалидных значений роли.

## Статус

Каркас создан. Содержательное заполнение начнется после утверждения требований
и модели ролей.
